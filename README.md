# Alifya Dhiva | Portfolio

Personal portfolio of **Alifya Dhiva**, Geologist and Data Engineer. It shows data engineering, machine learning and GIS projects, work experience, certificates and a CV viewer, in a skeuomorphic design.

Live site: https://alifyadhiva.vercel.app

## Tech stack
- Next.js 16 (App Router, static export), React 19, TypeScript
- Plain CSS design system (no UI framework), lucide-react icons

## Getting started
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in /out
```

## Deployment
Deployed on Vercel. Import the repository; the Next.js preset is detected automatically.

## Structure
```
src/app         pages and global styles
src/components  UI sections
src/data        site, project and certificate content
public          images, certificates and CV
```
